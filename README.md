 COVID-19 Data Analysis

 Project Description

This project analyzes COVID-19 data for different cities.

The project shows COVID-19 cases, recovered patients, and deaths. It also provides city-wise search and graphs for comparing COVID-19 cases and deaths.

 Cities:
 Ahmedabad
 Surat
 Vadodara
 Rajkot
 Gandhinagar
 Bhavnagar
 Jamnagar
 Junagadh

 Technologies Used:
 Python
 Pandas
 Matplotlib
 Seaborn

 Features:
 Show COVID-19 data
 Calculate total cases
 Calculate total recovered
 Calculate total deaths
 Search data by city
 Display cases bar chart
 Display deaths bar chart
 Compare COVID-19 cases
 Exit the program

 How to Run:
 Install Python.
 Install required libraries.
 Save the Python code as covid19.py.
 Run the file.
 Select an option from the menu.
 
 Project Output
The program displays COVID-19 data in table format and provides graphs for cases and deaths.

 Conclusion
This project helps to understand COVID-19 data using Python and data visualization techniques.
